### AI-Powered Vehicle Assistant

**Moto-Spec Genie** is an AI-powered vehicle assistant designed to make car and bike information easier to explore.

The application combines a **Flask backend, Gemini API, custom vehicle datasets and RAG-based information retrieval** with a responsive frontend.

### ✨ Highlights

| Feature | Description            |
| ------- | ---------------------- |
| 🚗      | Car specifications     |
| 🏍️     | Bike specifications    |
| ⚖️      | Vehicle comparisons    |
| 🤖      | AI assistance          |
| 🔎      | Vehicle information    |
| ⛽       | Fuel-cost calculation  |
| 💬      | AI-powered interaction |
| 📱      | Responsive interface   |

### 🧠 How It Works

```text
User Query
    ↓
Flask Application
    ↓
Vehicle Dataset / RAG
    ↓
Relevant Information
    ↓
Gemini API
    ↓
AI Response
```

### 🧰 Tech Stack

`Python` `Flask` `Gemini API` `RAG` `HTML` `CSS` `Bootstrap` `JavaScript`

* 📚 Course guidance
* 🛣️ Learning-path suggestions
* 💻 Coding practice
* 📝 Aptitude tests
* 👤 User profile management
* 🔐 Authentication
* 📊 Career matching

<summary><b>📧 Email Spam Detection</b></summary>

<br>

### Machine Learning Classification Project

A machine learning project that predicts whether an email is **spam or not spam**.

This project helped me work with text data and understand how raw text can be transformed into numerical features that machine learning algorithms can use.

### ✨ What I Worked On

* Data loading and exploration
* Text preprocessing
* TF-IDF feature extraction
* Feature transformation
* Model training
* Naive Bayes classification
* Model evaluation

### 🧠 Machine Learning Pipeline

```text
Raw Email Text
      ↓
Text Preprocessing
      ↓
TF-IDF Vectorization
      ↓
Train/Test Split
      ↓
Multinomial Naive Bayes
      ↓
Prediction
      ↓
Model Evaluation
```

### 🧰 Tech Stack

`Python` `Pandas` `Scikit-learn` `TF-IDF` `Multinomial Naive Bayes`
